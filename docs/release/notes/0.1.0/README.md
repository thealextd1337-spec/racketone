# Entwurf für 0.1.0

Die internen Notes beschreiben den geplanten Stand nach beiden Android-Integrations-Merges. Vor dem Upload ist im Release-Protokoll die Pflicht-Checkbox „Notes gegen Build geprüft“ abzuhaken.

Für `alpha` und `production` sind vor jeder Promotion eigene, am Kandidaten geprüfte Dateien unter `<track>/de-DE.txt` und `<track>/en-US.txt` anzulegen. Die Produktionsnotes enthalten keine Test-Aufforderung. Fehlende Zieltrack-Notes blockieren den Workflow; interne Notes werden nicht automatisch übernommen.
